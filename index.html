GPT 로그인

ChatGPT 계정이나 OpenAI API 키로 로그인하면 GPT가 논문을 번역하고 정리합니다.

ChatGPT Plus·Pro 플랜의 사용량으로 분석합니다. API 키나 별도 결제가 필요 없습니다.

ChatGPT 로그인은 http://127.0.0.1 주소로 열었을 때만 가능합니다. 터미널에서 python3 serve.py 를 실행한 뒤 http://127.0.0.1:8000 을 여세요.

또는 API 키로 로그인

보통 sk-로 시작합니다. 프로젝트 키 등 다른 형식도 사용할 수 있습니다.

API 키 발급받기 → platform.openai.com/api-keys

키는 이 브라우저에만 저장됩니다. 서버로 전송되지 않으며 api.openai.com 호출에만 사용됩니다. ChatGPT 로그인 정보도 이 브라우저(127.0.0.1 주소)에만 저장됩니다.

API 사용량은 OpenAI 계정에 과금됩니다.
