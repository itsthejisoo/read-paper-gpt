# 논문 함께 읽기

논문 링크(또는 PDF 파일)를 넣으면 GPT가 **전문 한글 번역**과 **구조화된 요약**(문제정의 / 해결방법(제안 기법) / 결과(정확한 수치) 및 장점 / 단점 및 한계점 / 핵심기술)을 만들어 주는 정적 HTML 사이트입니다. 별도 백엔드 없이 동작하며, API 키 모드는 브라우저가 OpenAI API를 직접 호출하고 ChatGPT 모드는 함께 들어 있는 로컬 중계 스크립트(`serve.py`)를 거칩니다.

## 실행 방법

빌드 과정이 없습니다. 로그인 방법에 따라 여는 방법이 다릅니다.

1. **ChatGPT 계정으로 사용(권장)** — 터미널에서 이 폴더로 이동해 아래를 실행한 뒤 브라우저에서 `http://127.0.0.1:8000` 을 엽니다.

   ```
   python3 serve.py
   ```

   `serve.py`는 표준 라이브러리만 쓰는 작은 로컬 서버입니다. 정적 파일을 서비스하면서 ChatGPT 플랜 호출을 같은 주소(`/__rpt/openai/…`)에서 `api.openai.com`으로 중계하고, 토큰은 요청에 실려 지나갈 뿐 저장하거나 기록하지 않으며, `127.0.0.1`(루프백)에만 바인딩됩니다. 중계가 필요한 이유는 브라우저가 플랜 토큰으로 `api.openai.com`을 직접 호출하면 응답에 CORS 허용 헤더가 없어 결과를 읽지 못하기 때문입니다. `python3 -m http.server`처럼 중계 기능이 없는 서버로 띄우면 로그인 버튼이 `serve.py`를 실행하라는 안내 문구를 보여 줍니다. 포트는 `python3 serve.py --port 8080`처럼 바꿀 수 있습니다.

   ChatGPT 로그인은 `http://127.0.0.1` 주소에서만 동작합니다. `localhost`로 열면 로그인 버튼이 `127.0.0.1` 주소로 옮겨 주고, `file://`로 열면 API 키 로그인만 가능합니다. 포트는 바꿔도 되지만 로그인 정보가 주소(origin)별로 저장되므로 이 앱 전용 포트를 정해 두는 것이 좋습니다.
2. **API 키로 사용** — `index.html`을 더블클릭해 브라우저(Chrome, Edge, Firefox, Safari 최신 버전)로 열어도 되고, `python3 -m http.server` 같은 아무 정적 서버로 띄워도 됩니다. `file://` 주소에서도 OpenAI 호출이 허용됩니다.

마크다운·수식·차트 라이브러리(marked, DOMPurify, KaTeX, Chart.js)는 cdnjs에서 불러오므로 인터넷 연결이 필요합니다. CDN을 불러오지 못하면 수식은 LaTeX 원문으로, 레이더 차트는 표로 표시됩니다.

## GPT 로그인

첫 실행 시 **GPT 로그인** 창이 뜹니다. 두 방법 중 하나를 고르며, 설정의 **계정** 항목에서 언제든 **다른 방법으로 로그인**으로 바꿀 수 있습니다.

### ChatGPT로 계속하기 (ChatGPT 플랜 사용)

- ChatGPT Plus·Pro 플랜의 사용량으로 분석합니다. API 키나 별도 결제가 필요 없습니다. OpenAI의 "Sign in with ChatGPT" 기능을 사용하며, 현재 **preview** 단계라 동작과 한도가 바뀔 수 있습니다.
- 버튼을 누르면 ChatGPT 로그인 페이지로 이동합니다. 처음에는 이 앱이 **Read Paper Together** 라는 이름으로 등록되고, 로그인 뒤 앱이 플랜 사용량을 쓰도록 허용(동의)하면 앱으로 돌아옵니다. 허용하지 않으면 API 키로 로그인해야 합니다.
- 사용량: Plus는 모든 앱이 5시간 한도를 함께 쓰고, Pro는 5시간 한도가 없습니다. 앱별 주간 상한(10~100%)은 ChatGPT 설정 → 앱에서 정합니다. 한도에 도달하면 분석을 멈추고 **사용량 관리** 링크(ChatGPT 설정 → 사용량)와 **API 키로 전환** 버튼을 보여 주며 자동으로 재시도하지 않습니다. 남은 섹션은 **실패 섹션 모두 재시도**로 이어서 번역할 수 있습니다.
- API 키 모드와 다른 점: 예상 비용을 표시하지 않고 결과 헤더에 **ChatGPT 플랜 사용 중** 칩이 붙습니다. 업로드한 PDF는 Files API에 올리지 않고 매 호출에 파일 내용을 함께 보냅니다(저장되지 않음). 출력 토큰 상한(`max_output_tokens`)을 지정할 수 없어 아주 긴 섹션은 모델 자체 한도에 의존합니다. 모델 목록은 플랜에서 쓸 수 있는 모델로 채워집니다. 목록을 받지 못하면 홈 화면과 설정에 이유(HTTP 상태·오류 코드)가 표시되고 **모델 목록 다시 불러오기**로 재시도할 수 있습니다.
- 보안: 로그인 토큰은 이 브라우저의 `localStorage`에 `127.0.0.1:<포트>` 주소 단위로 저장되며 ChatGPT 로그인 서버와 `api.openai.com` 호출에만 쓰입니다. 플랜 호출은 로컬 중계(`serve.py`)를 거치지만 토큰은 메모리에서 그대로 전달될 뿐 디스크나 로그에 남지 않습니다. 같은 주소에서 띄운 다른 앱이 이 저장소를 읽을 수 있으므로 전용 포트를 쓰고, 공용 PC에서는 **로그아웃**으로 연결을 해제(토큰 폐기)하세요. API 키로 전환해도 ChatGPT 연결은 같은 방식으로 해제됩니다. 브라우저는 ID 토큰의 서명을 검증할 수 없어 클레임만 확인합니다(토큰은 TLS로 OpenAI에서 직접 받습니다).
- 로그인이 만료되면(토큰 갱신 실패) 진행 중인 작업을 멈추고 로그인 창을 다시 띄웁니다. 앱 등록 정보는 남아 있어 다음 로그인은 같은 계정·앱 이름으로 진행됩니다.
- 개인·로컬 사용이나 오픈소스 프로젝트는 별도 승인 없이 쓸 수 있습니다. 유료 서비스나 원격 호스팅으로 제공하려면 OpenAI의 승인이 필요합니다.

### OpenAI API 키

- [platform.openai.com/api-keys](https://platform.openai.com/api-keys)에서 발급한 OpenAI API 키를 넣고 **로그인**을 누르면 `GET /v1/models` 호출로 키를 확인합니다.
- 키는 이 브라우저의 `localStorage`(`rpt.apiKey`)에만 저장되며, 어떤 서버로도 전송되지 않고 `api.openai.com` 호출에만 사용됩니다. 공용 PC에서는 사용 후 상단의 **로그아웃**으로 키를 지워 주세요.
- 키가 더 이상 유효하지 않으면(401) 진행 중인 작업을 멈추고 로그인 창을 다시 띄웁니다.
- 로그인 시 사용 가능한 `gpt-5`/`gpt-6` 계열 모델 목록을 받아 설정의 **모델** 선택지로 채웁니다. 기본값은 `gpt-5.4-mini`입니다.

## 사용 방법

1. 홈에서 논문 링크를 붙여넣거나 PDF를 끌어다 놓고 **분석 시작**(`⌘/Ctrl + Enter`)을 누릅니다.
2. 결과 화면은 세 탭으로 구성됩니다.
   - **요약**: 한 줄 요약, 한눈에 보기(문제 → 방법 → 결과), 다섯 항목 정리, 파이프라인 흐름도, 지표 표(인라인 바 + 변화 칩), 5축 평가 레이더(1~5점, GPT 추정), 장점 vs 한계점, 핵심기술 칩.
   - **전문 번역**: 섹션별로 스트리밍되는 번역 카드, 목차, 원문 나란히 보기, 글자 크기, 수식 원문 보기.
   - **원문**: PDF 뷰어(사이트가 허용하는 경우) 또는 새 탭 열기 링크.
3. 실패한 섹션은 카드의 **다시 시도** 또는 상단의 **실패 섹션 모두 재시도**로 다시 번역할 수 있습니다. 요약이 실패하면 **요약 다시 생성**을 누릅니다.
4. **내보내기**에서 Markdown/HTML 파일 다운로드, 요약 복사, 전체 복사를 할 수 있습니다.
5. 분석 결과는 브라우저(IndexedDB, 불가 시 localStorage)에 저장되어 홈의 **최근 분석**에서 다시 열 수 있습니다. 업로드한 PDF 파일 자체는 저장되지 않으므로 다시 열었을 때 원문을 보려면 파일을 다시 선택해야 합니다.

### 설정 (상단 톱니 아이콘 또는 `,` 키)

- **모델**: 요약·번역 모두 같은 모델을 사용합니다.
- **추론 강도**: 없음/낮음/중간/높음. 논문 구조 파악과 요약에만 적용되며 번역은 항상 추론 없이 실행됩니다.
- **동시 번역 수**: 1~5(기본 3). 429 오류가 잦으면 줄여 주세요.
- **테마**, **번역 글자 크기**.

### 단축키

`⌘/Ctrl + Enter` 분석 시작 · `/` 링크 입력 포커스 · `1` `2` `3` 탭 전환 · `[` `]` 이전/다음 섹션 · `t` 목차 포커스 · `s` 원문 나란히 보기 · `,` 설정 · `⌘/Ctrl + Shift + C` 전체 복사 · `Esc` 메뉴 닫기

## 비용

- ChatGPT 플랜 모드에서는 과금 대신 플랜 사용량이 차감되며 예상 비용을 표시하지 않습니다. 아래는 API 키 모드 기준입니다.
- 모든 호출은 사용자의 OpenAI 계정에 과금됩니다. 논문 한 편당 호출은 구조 파악 1회 + 요약 1회 + 섹션(3~5쪽 단위) 번역 N회이며, 매 호출에 PDF 전체가 입력으로 들어갑니다. 동일한 접두부를 사용하므로 두 번째 호출부터는 대부분 프롬프트 캐시(입력 단가의 10%)가 적용됩니다.
- 결과 헤더에 입력/출력 토큰과 **예상 비용**(모델 단가표 기준, 알 수 없는 모델은 `-`)을 표시합니다. 예를 들어 `gpt-5.4-mini`로 15쪽 논문을 처리하면 대략 입력 15만~25만 토큰(대부분 캐시) + 출력 2만~4만 토큰 수준입니다.
- 참고문헌은 번역하지 않고 초록은 구조 파악 결과를 재사용해 비용을 줄입니다. 부록은 **부록 포함** 체크를 끄면 제외할 수 있고, 카드의 **번역** 버튼으로 필요한 부록만 번역할 수 있습니다.

## 지원 링크

| 종류 | 예시 | 처리 |
|---|---|---|
| arXiv (abs/pdf/html, export, ar5iv, alphaxiv, Hugging Face Papers, DOI 10.48550, `arXiv:ID`, 맨 ID) | `https://arxiv.org/abs/1706.03762` | `https://arxiv.org/pdf/<id>`로 변환, 나란히 보기 가능 |
| OpenReview | `https://openreview.net/forum?id=...` | `pdf?id=` 로 시도. 봇 차단으로 실패할 수 있음 → PDF 업로드 권장 |
| ACL Anthology | `https://aclanthology.org/2023.acl-long.1/` | `.pdf` 로 변환, 나란히 보기 가능 |
| CVF Open Access (CVPR/ICCV/WACV) | `.../html/..._paper.html` | `/papers/..._paper.pdf` 로 변환 |
| PMLR (ICML 등) | `https://proceedings.mlr.press/v202/abbas23a.html` | 권별 PDF 경로로 변환 |
| NeurIPS proceedings | `.../hash/...-Abstract-Conference.html` | `-Paper-Conference.pdf` 로 변환 (페이지 내 표시 불가, 새 탭 열기) |
| bioRxiv / medRxiv | `https://www.biorxiv.org/content/10.1101/...` | `.full.pdf` 로 변환 (medRxiv는 차단될 수 있음) |
| Semantic Scholar | `https://www.semanticscholar.org/paper/<id>` | API로 arXiv/공개 PDF를 찾아 변환 |
| 직접 PDF 링크 | `https://example.edu/paper.pdf` | 그대로 사용 |
| IEEE Xplore, ACM DL, ScienceDirect, Springer, Nature, Wiley 등 | — | 자동 수집 불가. 기관 계정으로 내려받아 **PDF 업로드** |
| Google Scholar | — | 검색 페이지는 지원하지 않음. 결과의 PDF/arXiv 링크 사용 |

PDF 업로드는 50MB 이하, 100쪽 이하를 권장합니다. API 키 모드에서는 업로드한 파일을 OpenAI Files API(`purpose=user_data`)에 24시간 만료로 저장하고 분석이 끝나면 삭제를 시도합니다. ChatGPT 플랜 모드에서는 파일을 저장하지 않고 매 호출에 함께 보냅니다.

## 제한 사항

- OpenAI 서버가 PDF를 직접 내려받으므로 로그인·봇 차단·유료 사이트의 링크는 실패합니다. 이 경우 "OpenAI가 PDF를 가져오지 못했습니다" 안내가 뜨며 파일 업로드로 우회할 수 있습니다.
- 섹션 범위는 모델이 페이지 번호로 추정하므로 섹션 경계에서 일부 문장이 빠지거나 겹칠 수 있습니다. 앱이 직후 섹션 제목이 섞인 부분을 잘라내고(배지 "경계 정리됨"), 출력 한도로 잘린 섹션은 남은 페이지를 나눠 이어 붙입니다(배지 "일부 잘림").
- 요약의 수치와 평가 점수는 모델이 논문에서 추출·추정한 값입니다. 표의 **출처** 열(Table N 등)로 원문을 확인하세요.
- 동시 호출이 많으면 429(요청 한도)가 발생할 수 있습니다. 자동으로 2초·6초·15초 간격으로 재시도하고, 두 번째 429부터는 동시 번역 수를 절반으로 줄입니다.
- 브라우저 저장 공간(localStorage 폴백 시 약 5MB) 한도를 넘으면 가장 오래된 기록부터 삭제됩니다. 긴 논문을 여러 편 저장할 때는 IndexedDB를 지원하는 브라우저(대부분의 데스크톱 브라우저)를 권장합니다.
- `file://`로 열 때 Safari는 세션 종료 시 저장소를 비울 수 있으며, 일부 브라우저에서는 IndexedDB가 막혀 localStorage로 대체됩니다.
- Chart.js 레이더 차트는 캔버스라 고대비·확대 환경에 취약하므로 항상 옆에 점수 표를 함께 보여 줍니다.
- 모델 목록과 단가표는 2026년 11월 기준이며, OpenAI의 모델 정책 변경에 따라 달라질 수 있습니다.

## 검증 (선택)

`test/` 폴더에는 OpenAI 호출을 가짜 응답으로 바꿔 API 비용 없이 앱 전체 흐름을 헤드리스 Chrome에서 확인하는 스크립트가 있습니다. 설치된 Google Chrome과 Node.js가 필요합니다.

```
python3 serve.py --port 8765   # 프로젝트 루트에서 별도 터미널로 실행 (중계는 페이지 안의 mock이 대신하므로 python3 -m http.server 8765 --bind 127.0.0.1 도 가능)
cd test && npm install
npm run test:flow        # 로그인 → 분석 → 요약·번역 렌더링 → 내보내기 → 새로고침 복원 → 로그아웃
npm run test:flow:file   # 같은 흐름을 file:// 로 실행
npm run test:scenarios   # 업로드, 중단·재시도, 401 재로그인, 출력 잘림 이어받기, 부록 수동 번역 등
npm run test:chatgpt     # ChatGPT 로그인(모의 OAuth) → 플랜 호출 규격, 토큰 갱신, 사용 한도, 업로드, 거부·권한 누락, 중계 없음, file:// 등
npm run test:proxy       # serve.py 중계: 헤더 전달, 스트리밍, 오류 통과, 중단 전파, 바인딩 제한 (가짜 상위 서버 사용, Chrome 불필요)
```

결과는 `test/out/<이름>/report.json`과 스크린샷으로 저장됩니다. 실제 OpenAI 응답 품질은 이 스크립트로 검증되지 않습니다.

## 파일 구성

```
index.html   마크업, CDN 태그
styles.css   디자인 토큰과 컴포넌트 스타일(라이트/다크, 반응형, 인쇄)
prompts.js   시스템 지시문, 프롬프트, 구조화 출력 스키마, 기본 용어집 (window.RPT_PROMPTS)
app.js       저장소, API 클라이언트, ChatGPT 로그인(OAuth), 링크 정규화, 작업 실행기, 렌더러, 라우터, UI (하나의 IIFE)
serve.py     로컬 서버: 정적 파일 서비스 + ChatGPT 플랜 호출을 api.openai.com으로 중계 (표준 라이브러리만 사용)
auth/callback/index.html   ChatGPT 로그인 뒤 돌아오는 콜백 페이지 (앱으로 되돌려 보냄)
.env.example   로컬 환경 변수 템플릿 (.env 로 복사해 사용, .env 는 커밋되지 않음)
test/        모의 OpenAI 서버(mock-openai.js)와 헤드리스 Chrome 검증 스크립트(run.js, run2.js, run3.js), 중계 서버 검증(proxy-test.js)
```

테스트·디버깅용으로 `window.RPT = { version, normalizeUrl, buildChunks, renderMarkdown, store, state, auth: { status } }`를 노출하며(토큰 값은 노출하지 않음), API 키 모드의 모든 `/v1/responses` 요청 본문에 `metadata: { app: 'rpt', task, chunk }`가 포함됩니다.
